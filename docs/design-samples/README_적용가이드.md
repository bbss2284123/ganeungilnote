# 가는길노트 — 블로그 UI 및 이미지 에셋 통합 적용 안내

## 방향
- 확정된 시안처럼 **흰 배경·글목록 중심·우측 사이드바**의 일반 블로그 형태를 유지한다.
- 큰 광고형 히어로 배너, 실시간 여행 뉴스/알림, 과도한 카드·애니메이션을 넣지 않는다.
- 여행지역·축제·교통·주차·맛집 정보의 **글씨 있는 사진형 썸네일**을 16:9로 통일한다.
- 콘텐츠 정보는 실제 공식 자료/허용된 API로 조회·검증한 뒤 표시한다.

## 파일 구성
1. `01_홈화면/`: 사용자와 합의된 PC 홈페이지 참고 이미지 + 모바일 시안.
2. `02_로고_파비콘/`: 투명 PNG 로고·SVG 로고·다크 배경용·파비콘 다중 크기.
3. `03_카테고리_아이콘/`: 여섯 가지 범주용 개별 PNG(256px)·SVG.
4. `04_글씨있는_썸네일/`: 각기 다른 사진과 제목을 사용한 1200×675px PNG·WebP 8종.
5. `05_지도_주차_정보그래픽/`: 동선 개념도, 주차장 위치 개념도, 주차요금·휴무·교통·맛집 비교 이미지 템플릿.
6. `06_SNS_공유/`: SNS 공유 썸네일(1200×630px).
7. `07_적용가이드/`: 적용 문서와 자산 목록.

## Grok 개발 지침
- 사이트 이름 '가는길노트', 블로그 콘텐츠는 `지역·여행정보`, `축제·행사`, `교통·가는법`, `주차정보`, `여행코스·맛집` 카테고리로 정리.
- 데스크톱은 본문 글 목록 약 75%, 우측 사이드바 약 25%. 모바일은 1열 목록, 사진 가로 미리보기 + 제목·요약 텍스트.
- 썸네일 글자 스타일은 제목 1~2줄, 부제 1줄, 카테고리 칩 1개; 작은 화면에서도 가독성을 유지하고 본문에 같은 텍스트를 중복 과하게 노출하지 않는다.
- 새 글은 사진 배경 이미지를 사용하되 제목/부제는 프로그램(HTML/CSS 또는 SVG/Pillow/Sharp)으로 합성해 일관성을 유지.
- HTML 본문에서 가격·휴무·시간표·평점은 **텍스트/표 데이터**로 렌더링하며, 이를 이미지로만 제공하지 않는다(검색·접근성·수정 용이성).
- 본문 이미지는 실제 검증된 현장 사진 또는 사용권한 확인된 이미지를 우선하며, AI 생성 사진을 실제 장소의 증거처럼 제시하지 않는다.
- 여행지도는 이 ZIP의 예시 그림처럼 친근하게 만들되, 실제 지도에 사용할 지리적 위치·진입로·주차장 위치·거리·도보 및 주행시간은 지도 API/공식 자료로 확인한다.
- 동선 일러스트를 실제 지도 대신 사용하지 않는다. 확인하지 않은 값(주차요금·운영시간·휴무일·별점·리뷰수·도보시간·조회수)은 표시하거나 자동 생성하지 않는다.
- 구글 리뷰 데이터는 Google Places API/표시·캐시 규정에 맞춰 사용, 분석 가능한 리뷰 수를 표기하고 근거 없이 전체 리뷰의 공통 의견으로 단정하지 않는다.
- SNS 게시물을 자동 추출할 때 저작권·플랫폼 약관 준수, 출처 링크 및 허용된 공유 방식 사용.
- 과거 글과 시안에 있던 행사 날짜나 비용은 실제 검증값이 아니므로 기사 데이터로 재활용하지 않는다.

## 이미지 운영 규격
- 게시글 썸네일 1200×675px, WebP 우선/PNG 예비. HTML `<img>`의 `alt`에는 사진과 주제의 객관적 설명.
- 업로드는 WebP 최적화 및 lazy loading, hero 미사용. 레이아웃 시프트 방지용 width/height 고정.
- 수정 가능한 본문 표를 기준으로 지도·주차 인포그래픽을 주기적으로 재생성.
- 모바일에서 정보성 이미지가 깨알 글씨가 되면 이미지 아래에 접근 가능한 동일 정보를 HTML 표로 재제공.

## 사용 시 주의
이 팩은 이미지 생성으로 만든 디자인 자료다. 일부 사진·동선·장소는 상상적 묘사나 참고 예시이고 실재 상황을 검증하는 자료가 아니다. 사이트 운영에 필요한 수치·평점·경로·행사 상태는 별도로 확인해야 한다.

폰트는 ZIP에 포함하지 않았다. 기본 CSS는 `font-family: "Noto Sans KR", "NanumSquare", sans-serif;` 등을 사용하고 필요한 폰트의 라이선스를 준수한다.
